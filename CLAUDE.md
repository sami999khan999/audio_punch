# Contributing conventions

## Commits and pull requests

Do not add AI attribution to anything committed or pushed here.

- No `Co-Authored-By:` trailer naming Claude, Anthropic, or `noreply@anthropic.com`.
  GitHub reads that trailer and lists the address as a repository contributor.
- No `Claude-Session:` trailer.
- No "Generated with Claude Code" footer in pull request descriptions.

Commits are authored by the repository owner. Write the message as a plain description
of the change and stop there.
